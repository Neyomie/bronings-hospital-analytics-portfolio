HOW TO READ THIS DOCUMENT

Each KPI has the eight required fields plus a baseline line. Baselines were verified from the validated exports in Phases 3 and 4. Where a KPI cannot be calculated from current data, the baseline says so and names the missing data.

Data sources use the SQL Server tables Daniel loaded (BroningsAnalytics, dbo schema). Column names match the CSV exports exactly.

Standard rules for every KPI:
- Count unique record IDs. Exact duplicates are removed first.
- Blank or text values in a numeric field are excluded and logged; they are never counted as zero.
- The reporting period is the financial quarter (or month, for statutory returns), filtered on the event date named in the formula.
- Specialty code GEN is mapped to GM before any grouping.
- ST-99 workforce records are test data and always excluded.

RAG convention: GREEN meets the Trust target, AMBER is within the tolerance stated, RED is worse than the tolerance.

KPI 01. ED 4-HOUR COMPLIANCE (4HT)

1. Name / abbreviation: ED 4-hour target compliance (4HT).
2. Formula:
   4HT % = COUNT(DISTINCT Attendance_ID WHERE ED_Minutes BETWEEN 0 AND 240) / COUNT(DISTINCT Attendance_ID) x 100
   where ED_Minutes = DATEDIFF(minute, Arrival_Date + Arrival_Time, Departure date + Departure_Time). Add 1,440 minutes when the departure time is earlier than the arrival time (crossed midnight).
   Calculate from the times, not from the Four_Hour_Breach flag. Attendances with no departure time stay in the denominator and count as non-compliant until corrected.
3. Data source: dbo.EDAttendances: Attendance_ID, Arrival_Date, Arrival_Time, Departure_Time, Total_ED_Time_Minutes (check only).
4. NHS England standard: 95% constitutional standard. Interim operational target 78% (March 2025, retained for March 2026).
5. Trust target: 90%. GREEN >=90%, AMBER 78-89.9%, RED <78%.
6. Operational owner: Clinical Director, Urgent and Emergency Care. Reported by Sarah Okafor, Performance Manager.
7. Business decision: Where flow breaks (triage, specialty review, waiting for a bed); whether to open escalation capacity; ED staffing levels.
8. Action trigger: RED for one week → Clinical Director runs a breach review of the longest 20 waits within 5 working days. RED for two consecutive weeks → escalate to Tom Nguyen and the daily site meeting, and open escalation beds under the surge plan.
Baseline: 83.17% (766 of 921 attendances with valid times). 79.79% if the 39 attendances with missing or negative times are counted as breaches.

2. Formula: LWBS % = COUNT(DISTINCT Attendance_ID WHERE Departure_Code = 'LWBS') / COUNT(DISTINCT Attendance_ID) x 100
3. Data source: dbo.EDAttendances: Attendance_ID, Departure_Code, Seen_by_Clinician_Time (validation: an LWBS record should have no seen time).

KPI 03. OUTPATIENT DNA RATE (DNA)

1. Name / abbreviation: Outpatient Did Not Attend rate (DNA rate).
2. Formula (correct definition):
   DNA % = COUNT(Attendance_Status = 'DNA') / ( COUNT(Attendance_Status = 'ATT') + COUNT(Attendance_Status = 'DNA') ) x 100
   Filtered on Appointment_Date within the financial quarter. Status codes are matched case-sensitively.
   Excel (Attendance_Status is column J in the current export): =COUNTIFS(J:J,"DNA",H:H,">="&Start,H:H,"<="&End) / (COUNTIFS(J:J,"ATT",H:H,">="&Start,H:H,"<="&End) + COUNTIFS(J:J,"DNA",H:H,">="&Start,H:H,"<="&End))
   Excluded from both numerator and denominator: CAN (cancelled by the hospital), REF (patient refused or rebooked in advance), blanks and non-standard values.
3. Data source: dbo.OutpatientAppointments: Appointment_ID, Attendance_Status, Appointment_Date, Specialty_Code, Clinic_Code, Referral_Source.
4. NHS England standard: <10% (Company Brief). No statutory target.
5. Trust target: <8%. GREEN <8%, AMBER 8-10%, RED >10%.
6. Operational owner: Outpatients Manager. Specialty breakdown goes to each Clinical Director.
7. Business decision: Reminder services (SMS 7 days and 48 hours before), booking rules and clinic overbooking levels. Every DNA is a lost slot for an RTT patient.
8. Action trigger: A specialty RED for a month → the Outpatients Manager targets that specialty's GP-referred bookings for reminder and partial-booking checks. Trust-wide RED for a quarter → item on the Planned Care board agenda.
Baseline: 14.07% (76 DNA / 540 ATT + DNA), RED. Worst: Orthopaedics 38.64%, Urology 20.75%, Ophthalmology 17.24%.

Why the three previously used formulas were wrong:
- Version A, 9.8% (Performance, KPI_Summary D14): =COUNTIF(F:F,"DNA")/COUNTA(F:F).
  COUNTA counts the header row, so it divides by rows + 1. It also puts CAN (and REF) appointments in the denominator; the patient had no chance to miss a slot the hospital cancelled. Both errors make the rate look lower than it is.
  It also uses a whole-column reference with no date filter, so the period changes every time data is pasted in. In the export we now receive, column F is Consultant_Code, not the status, so the formula would return 0.
- Version B, 12.4% (Finance_Reconciliation B7): not a formula. It is a number typed in September 2024, linked to no data, so it cannot change when performance changes and nobody can audit it. This is the figure the Board has been seeing.
- Version C, 14.1% (PAS report): uses a calendar month instead of the financial quarter, so it covers different appointments from the other two figures and cannot be compared with them or with the quarterly returns.
Also not adopted: the Process Notes suggestion (DNA / all non-blank rows) and the four-code denominator in the Phase 2 pack draft. Both still include CAN and REF, which dilutes the rate to 13.15% (76 / 578). The definition above replaces every earlier version.

KPI 07. THEATRE UTILISATION (TWO DEFINITIONS)

Theatre utilisation is measured two ways, and they answer different questions. Both are documented here.

KPI 07a. Theatre utilisation, hours-based (capped touch time) - THE NHS STANDARD
1. Name / abbreviation: Capped touch-time theatre utilisation (TU-hrs).
2. Formula: TU-hrs % = SUM(touch-time minutes inside the planned session) / SUM(planned session minutes) x 100
   Touch time = anaesthetic start to patient leaving theatre. Time after the planned session end is cut off ("capped"). Sessions cancelled in advance are excluded from the denominator; sessions cancelled on the day are included.
3. Data source: dbo.TheatreUtilisation does NOT contain the fields needed. Daniel must add to the TMS export: Session_Planned_Start, Session_Planned_End, Anaesthetic_Start, Patient_Out_Of_Theatre (per case) and Session_Status. Overrun_Minutes (already exported) is used only to check the cap.
4. NHS England standard: This is the national definition. GIRFT uses capped touch-time utilisation as its key theatre productivity measure, with an 85% target (Model Health System).
5. Trust target: 85%. GREEN >=85%, AMBER 75-84.9%, RED <75%.
6. Operational owner: Theatre Manager. Accountable executive: Divisional Director, Surgery.
7. Business decision: Productivity inside the lists: late starts, early finishes, turnaround time, and how lists are booked.
8. Action trigger: A specialty RED for 4 consecutive weeks → the Theatre Manager runs a list-level review (late starts, early finishes, turnaround) with the specialty lead. Trust RED for a month → a theatre productivity plan goes to the Planned Care board.
Baseline: 63% (Operations' current figure; cannot be checked until the time fields are exported).

KPI 07b. Theatre session uptake, sessions-based
1. Name / abbreviation: Theatre session uptake (TU-sess).
2. Formula: TU-sess % = SUM(Sessions_Used) / SUM(Sessions_Available) x 100. Weeks where Sessions_Used > Sessions_Available are flagged as data errors and corrected at source; the old workaround (setting Available = Used) is retired.
3. Data source: dbo.TheatreUtilisation: Week_Ending, Theatre_ID, Sessions_Available, Sessions_Used, Specialty_Code.
4. NHS England standard: No national standard. This is a local capacity measure.
5. Trust target: 95% PROPOSED, because a session that is not used at all is pure lost capacity. GREEN >=95%, AMBER 85-94.9%, RED <85%.
6. Operational owner: Theatre Manager. Session release and reallocation are agreed with the Divisional Director, Surgery.
7. Business decision: Whether whole sessions should be released and reallocated (e.g. to Orthopaedics, which has the longest waits), and how much funded capacity is unused.
8. Action trigger: A session released with less than 6 weeks' notice → offered to the specialty with the most 52-week risk. A theatre RED for 4 weeks → review of its session allocation in the job-planning round.
Baseline: 70.75% (1,538 of 2,174 sessions; 636 unused in the year), RED.

Which figure is which: the validated exports give a sessions-based figure of 70.75%, which matches Finance's 71%. The 63% reported by Operations is therefore the hours-based figure. The annotation in the Process Notes has these reversed.

Recommendation for the Phase 6 dashboard:
- Show both, as two separately named tiles side by side. Never use the bare label "Theatre utilisation". Each tile states its definition and denominator in its tooltip.
- The headline KPI is 07a, hours-based capped touch time, because it is the national GIRFT definition and the only one we can benchmark against peers. 07b sits next to it as "Session uptake".
- Add a small "gap" annotation (07b minus 07a). It shows how much time is lost inside sessions that do run: late starts, early finishes and turnaround.
- Until TMS exports the time fields, show 07a as "awaiting data" with Operations' 63% labelled "manual, unverified". Do not replace it with the sessions figure.
- Board papers quote both figures with their names, which ends the 63% vs 71% argument.


KPI 08. CANCELLED OPERATIONS RATE (CANCOPS)

1. Name / abbreviation: Last-minute cancelled elective operations rate (CancOps).
2. Formula (statutory): CancOps % = COUNT(elective operations cancelled by the hospital on or after the day of admission for non-clinical reasons) / COUNT(elective admissions, Admission_Type = 'ELEC') x 100, plus a count of cancelled patients not rebooked within 28 days.
   Interim proxy until reason and date are exported: SUM(Cancellations_Trust) / SUM(Cases_Planned) x 100.
3. Data source: dbo.TheatreUtilisation: Cancellations_Trust, Cancellations_Patient, Cases_Planned, Week_Ending. dbo.InpatientAdmissions: Admission_Type. Cancellation date and reason are needed from TMS.
4. NHS England standard: Every patient cancelled at the last minute for non-clinical reasons must be offered a new date within 28 days; reported in the statutory quarterly Cancelled Elective Operations return.
5. Trust target: <1% PROPOSED, and zero 28-day breaches. GREEN <1%, AMBER 1-2%, RED >2% or any 28-day breach.
6. Operational owner: Divisional Director, Surgery.
7. Business decision: Protecting elective beds and lists from emergency pressure; ring-fencing elective capacity.
8. Action trigger: Any 28-day breach → escalate to the Divisional Director the same week and rebook within 7 days. RED for a month → review of elective bed ring-fencing at the patient flow meeting.
Baseline: 6.74% (359 Trust cancellations / 5,324 cases planned). This is a minimum: 30 Trust-cancellation values are blank, and the proxy includes all hospital cancellations, not only last-minute ones.


KPI 09. BED OCCUPANCY RATE (BOR)

1. Name / abbreviation: General and acute bed occupancy rate (BOR).
2. Formula: BOR % = SUM over days(patients in a bed at midnight) / SUM over days(available beds) x 100
   Patient in bed at midnight on day D = Admission_Date <= D AND (Discharge_Date IS NULL OR Discharge_Date > D), per Ward_Code. Wards W-01 to W-07 only; W-08 is closed.
3. Data source: dbo.InpatientAdmissions: Episode_ID, Admission_Date, Discharge_Date, Ward_Code. Available beds per ward per day (380 total) come from the bed management system and are not in the exports.
4. NHS England standard: <92%.
5. Trust target: <85%. GREEN <85%, AMBER 85-92%, RED >92%.
6. Operational owner: Head of Patient Flow (site management).
7. Business decision: Escalation beds, discharge planning and the emergency vs elective bed split. High occupancy drives ED delays (KPI 01).
8. Action trigger: AMBER for 3 consecutive days → discharge-focused board rounds on all wards. RED on any day → OPEL escalation and a site huddle chaired by the Head of Patient Flow.
Baseline: Not calculable. The extract has no daily bed base, and 31 spells with no discharge date would inflate the count. Weekly concurrent-patient counts (Phase 4, Query 4) show W-01 above 10 patients in 11 of 25 weeks.


KPI 10. AVERAGE LENGTH OF STAY (ALOS)

1. Name / abbreviation: Average length of stay (ALOS).
2. Formula: ALOS = SUM(DATEDIFF(day, Admission_Date, Discharge_Date)) / COUNT(DISTINCT Episode_ID with a Discharge_Date in the period). Reported separately for ELEC and EMER.
   Calculate from the dates. Do not use the stored Length_of_Stay column (6 negative values) or Bed_Days (34 mismatches).
3. Data source: dbo.InpatientAdmissions: Episode_ID, Admission_Date, Discharge_Date, Admission_Type, Specialty_Code.
4. NHS England standard: <4.5 days (Company Brief). Benchmarked by HRG through the Model Health System.
5. Trust target: <4.5 days. GREEN <4.5, AMBER 4.5-5.0, RED >5.0.
6. Operational owner: Integrated Discharge Team Manager.
7. Business decision: Delayed discharges, frailty pathways, community capacity. Each day saved frees beds for ED admissions.
8. Action trigger: A specialty AMBER or RED for a month → review of stranded patients (staying over 7 days) with the specialty. Any patient staying over 21 days → escalation to the weekly long-length-of-stay review.
Baseline: 3.87 days overall (4,543 bed days / 1,173 discharged spells), GREEN. Elective 2.88 days; emergency 4.65 days (AMBER).


KPI 11. 30-DAY EMERGENCY READMISSION RATE

   The flag is derived from dates, not taken from the stored Readmission_Flag, which does not match this logic.

4. NHS England standard: <10% (Company Brief). NHS Outcomes Framework indicator.
5. Trust target: <10%. GREEN <10%, AMBER 10-12%, RED >12%.
6. Operational owner: Medical Director. Specialty review by each Clinical Director.
7. Business decision: Whether patients are discharged too early, and the quality of discharge plans and follow-up.
8. Action trigger: A specialty above 10% for a quarter → a case-note audit of 20 readmissions by that specialty's Clinical Director. Trust above 12% → report to the Quality Committee.
Baseline: 9.58% (112 / 1,169) using the stored flags with the 44 blanks back-filled. Re-deriving every flag from dates gives 17.58%. Neither figure is reliable until the NHS Number duplication is fixed (317 inpatient NHS Numbers have conflicting surnames).

KPI 15. PATIENT SAFETY INCIDENT RATE (PSI)

Baseline: Not calculable. LFPSE data is needed.

KPI 18. RTT CLOCK START/STOP ACCURACY (RTT-VAL)

1. Name / abbreviation: RTT clock start/stop accuracy (RTT-VAL).
